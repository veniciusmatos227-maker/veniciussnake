# Jogo da Cobrinha

Projeto acadêmico de um jogo da cobrinha feito com HTML, CSS e JavaScript puro.

## Como executar no computador
1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador (Chrome, Edge, Firefox etc.).
3. Clique em **Iniciar jogo**.

## Como publicar gratuitamente no GitHub Pages
1. Entre em https://github.com e faça login.
2. Clique em **New repository** (Novo repositório).
3. Dê um nome, por exemplo `jogo-da-cobrinha`, e escolha **Public**.
4. Envie os arquivos `index.html` e `README.md` para o repositório (Add file > Upload files).
5. Abra **Settings > Pages**.
6. Em **Build and deployment**, selecione **Deploy from a branch**.
7. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
8. Aguarde a publicação. O endereço aparecerá na própria tela do GitHub Pages, geralmente no formato:
   `https://SEU-USUARIO.github.io/jogo-da-cobrinha/`

## Controles
- Computador: setas do teclado ou W, A, S, D.
- Pausar/continuar: barra de espaço ou botão **Pausar**.
- Celular: botões direcionais ou deslize o dedo sobre o tabuleiro.

## Funcionalidades
- Pontuação de 10 pontos por fruta.
- Recorde salvo no navegador com `localStorage`.
- Velocidade aumenta conforme a pontuação.
- Tela de pausa, fim de jogo e reinício.
- Layout adaptável a computador e celular.

## Sobre a atividade
O projeto demonstra a aplicação de estrutura HTML, estilização CSS, lógica de programação em JavaScript, eventos de teclado e toque, manipulação do Canvas e armazenamento local no navegador.
