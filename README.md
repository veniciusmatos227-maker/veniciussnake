# Jogo da Cobrinha

## Como executar no computador
1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador 
3. Clique em **Iniciar jogo**.

## Controles
- Computador: setas do teclado ou W, A, S, D.
- Pausar/continuar: barra de espaço ou botão **Pausar**.
- Celular: botões direcionais ou deslize o dedo sobre o tabuleiro.

## Funcionalidades
- Pontuação de 10 pontos por fruta.
- Recorde salvo no navegador com `localStorage`.
- Velocidade aumenta conforme a pontuação.
- Tela de pausa, fim de jogo e reinício.
- Layout adaptável a computador e celular.

## Sobre a atividade
O projeto demonstra a aplicação de estrutura HTML, estilização CSS, lógica de programação em JavaScript
